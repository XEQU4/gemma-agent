Дата: 30.10.2026. Проверены оба файла `submission/adapters/{main_lora,tool_lora}/adapter_model.safetensors`.

**Факт:** в каждом adapter обе матрицы B полностью нулевые, обе матрицы A не содержат нулей.
Все значения конечны. Для каждой пары `B @ A = 0`.
Каждый adapter содержит 108544 элементов: 54272 нулевых (50%) и 54272 ненулевых.

## Метод

Статистика рассчитана по **всем значениям tensor data каждого файла отдельно**, не по заголовку и не по одному представителю одинаковых файлов.
Использован Python 3.14.0, только стандартные json/struct/math/hashlib; модель и runtime не загружались.
Первые 8 байт прочитаны как little-endian длина JSON header; границы проверены до чтения.
Проверены уникальность JSON keys, shape, dtype, offsets, длины, отсутствие перекрытий/пробелов и полный охват payload.
У каждого файла размер 217672 bytes: 8 bytes длины, 576 bytes header, 217088 bytes tensor data.

Каждое BF16 значение декодировано из little-endian uint16: bits сдвинуты на 16 в IEEE float32.
Нулём считается точное числовое значение 0 (включая signed zero), без epsilon.
Счётчики zero/NaN/Inf дополнительно сверены непосредственно с BF16 bit masks.
Все данные конечны, поэтому приведённые min/max относятся ко всему tensor.
